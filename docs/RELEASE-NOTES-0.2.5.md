# Tingyi 0.2.5

Tingyi helps you follow conversations in person, with bilingual captions and translations you can listen to through headphones. A floating caption window keeps the conversation visible while you use other apps.

This version brings a smaller Windows download, with the required runtimes included, and improves caption history navigation.

**[Download for Windows](https://github.com/yachael/Tingyi/releases/download/v0.2.5-preview/Tingyi-Windows-x64-0.2.5-preview.exe)** · Windows 11 x64 · [Getting started](https://github.com/yachael/Tingyi/blob/main/docs/GETTING-STARTED.md)

## Français

Tingyi accompagne les conversations en face à face avec des sous-titres bilingues et une traduction au casque. La fenêtre flottante permet de garder les sous-titres sous les yeux pendant que vous utilisez d'autres applications.

Cette version propose un téléchargement Windows plus léger et améliore la navigation dans l'historique des sous-titres.

[ Télécharger pour Windows ](https://github.com/yachael/Tingyi/releases/download/v0.2.5-preview/Tingyi-Windows-x64-0.2.5-preview.exe)
